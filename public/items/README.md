# Item Images Directory

Place transparent PNG images of clothing items here, organized by category:

- `tops/` - Shirts, jackets, sweaters, etc.
- `bottoms/` - Pants, skirts, shorts, etc.
- `shoes/` - Boots, sneakers, sandals, etc.
- `accessories/` - Jewelry, belts, etc.
- `bags/` - Handbags, purses, etc.
- `hats/` - Hats, caps, etc.

All images should be transparent PNGs that can be layered on the base avatar.
